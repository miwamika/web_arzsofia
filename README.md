# K-Beauty Shop | Корейская косметика

Интернет-магазин корейской косметики, разработанный в рамках лабораторной работы.

## Реализованный функционал
- Каталог товаров с фотографиями, описанием и ценами.
- Добавление товаров в корзину.
- Изменение количества товаров и автоматический пересчет итоговой суммы.
- Удаление товаров из корзины.
- Сохранение состояния корзины в `localStorage` (данные не теряются при обновлении страницы).
- Модальное окно оформления заказа с валидацией полей.
